내 문서 관리 방식

A안의 메인 화면 안에서 포트폴리오·이력서와 버전을 어떻게 보여줄지 선택해줘.

추천 · 폴더 구조

A. 문서 트리 + Markdown 미리보기

왼쪽에서 포트폴리오·이력서와 버전을 폴더처럼 선택하고, 오른쪽에서 MD 렌더링 결과를 본다. 버전 관리 목적이 가장 분명하다.

탐색 쉬움

B. 문서 카드 + 상세 Drawer

문서를 카드로 넓게 보여주고 선택하면 상세 미리보기를 연다. 첫 화면은 편하지만 버전 이동이 한 단계 더 필요하다.

간결함 우선

C. 상단 탭 + 버전 요약

포트폴리오·이력서를 탭으로 바꾸고 버전은 요약 영역에 둔다. 화면은 단순하지만 여러 버전 비교에는 약하다.
